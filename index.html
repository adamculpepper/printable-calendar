About

A calendar generator that prints straight from the browser. It is a static page with no build step and no framework, and the source is on GitHub under the MIT license. Whatever you set up here is in the address bar, so a configuration is a link you can keep or send on.

Holiday dates come from holidate, an MIT-licensed library by Zachary Gomez. It is installed from npm and bundled into this page rather than fetched at runtime, and its license travels with it in vendor/holidate. It covers United States holidays, which is why the Holidays control is US only. Easter and the dates derived from it are recalculated here so they stay right outside the years the library's lookup table was built for.

Type is set in the system fonts unless you pick something else, in which case the page loads it from Google Fonts; if it cannot, the calendar falls back to the system fonts and prints the same as it always did. Page views go to Google Analytics. Those are the only two things here that reach the network, and neither of them ends up on the paper.
